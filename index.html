The missing link

No publicly available dataset exists for Phosphorus deficiency in tomato leaves. No existing system combines nutrient deficiency detection, co-occurrence-aware disease detection, treatment monitoring, and market price forecasting in one platform for Sri Lankan farmers. TomatoDoc addresses all four problems together.

The question TomatoDoc answers

Sri Lankan tomato farmers have no affordable tool that can diagnose plant health from a smartphone photograph, track whether treatment is working, and advise when to sell for maximum profit, all in one place.

  1. Detect six tomato leaf nutrient deficiency classes with 93 percent or higher test accuracy.
  2. Detect and localise co-occurring leaf disease symptoms using YOLOv8s.
  3. Monitor seven-day treatment response with U-Net segmentation.
  4. Forecast tomato market prices using LSTM and XGBoost with SHAP explanations.
  1. 01Dataset Collection
    Collected public tomato leaf and fruit disease images.
  2. 02Data Preprocessing
    Split datasets before augmentation and transformed training data.
  3. 03Model Training
    Compared CNN Scratch, VGG16, ResNet50, and MobileNetV2.
  4. 04Object Detection
    Trained YOLOv8s to localise multiple symptoms.
  5. 05Treatment Monitoring
    Estimated severity across a seven-day window.
  6. 06Price Forecasting
    Compared ARIMA, SARIMA, Random Forest, XGBoost, LSTM, and GRU.
  7. 07RAG System
    Connected ChromaDB and Groq Llama to agricultural guidelines.
  8. 08Mobile Application
    Integrated components through Flask and FastAPI APIs.

System Components

Five focused models, one farmer-first application. Each component is independently evaluated and designed to work as part of the larger system.
